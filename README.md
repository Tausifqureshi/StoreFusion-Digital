## Overview

StoreFusion Digital is a production-ready single-page e-commerce web application built with React, Redux Toolkit, and Firebase. It implements an end-to-end purchasing workflow including user authentication, real-time customer reviews, state persistence, and integrated checkout processing. The codebase emphasizes modular component architecture, predictable data flow, and responsive design across all devices.

## Tech Stack

- **Frontend:** React 18, Vite 7, React Router DOM 7
- **State Management:** Redux Toolkit, redux-persist
- **Styling:** Tailwind CSS, Material UI, Framer Motion
- **Backend & Database:** Firebase Authentication, Firebase Realtime Database
- **Payment Processing:** Razorpay Checkout SDK
- **Data Visualization:** Chart.js, react-chartjs-2

---

## Key Features

- **Customer Reviews & Testimonials:** Allows authenticated users to submit, edit, and delete product reviews with 5-star ratings synchronized via Firebase.
- **Persistent Shopping Cart:** Maintains cart items and price calculations locally across browser reloads using redux-persist.
- **Product Catalog & Filtering:** Provides instant search, category filtering, and customizable price range adjustments.
- **User Authentication:** Supports secure Firebase registration, sign-in, session retention, and protected customer routes.
- **Payment Gateway Integration:** Integrates a native Razorpay checkout modal for UPI, card, and netbanking transactions.
- **Admin Management Panel:** Features a centralized dashboard for inventory control, order tracking, and review moderation.

## Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/Tausifqureshi/StoreFusion-Digital.git
cd StoreFusion-Digital
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
